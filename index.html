About this project & how AI is used
  • Every AI-suggested building match or generated line is reviewed by a human before it's used — AI assists curation, it doesn't replace it.
  • All background photos are openly licensed (Public Domain or CC0) and credited by name in the Credits panel above, with a link to the source.
  • Live AI features (narrative generation, if enabled) are opt-in toggles, never the only path through the story.
  • No personal data is collected from visitors to this site.
